Superagent 使用介绍

Created2026-11-21|Updated2026-11-21
|Post View:

Superagent 是一个常驻在 GitHub 仓库里的自主编码代理。你在 issue 或 PR 评论里 @ 它并说明需求，它会自己开分支、改代码、跑检查，最后把结果以 PR 的形式回复到原评论。

用法很简单：在仓库里新建一个 issue，或者找到相关的 PR，在评论里 @ 代理账号，把要做的事说清楚。例如：

代理会把这条评论变成一项任务，在独立分支上完成修改。如果涉及代码，它会提交 PR 并在原评论里附上链接；对 PR 的修改意见，直接在 PR 里继续 @ 它即可，它会在同一个 PR 上更新。最后由人来 review 和合并。

几个让结果更稳的小建议：

  • 一次只提一件事，范围越小越好。
  • 给出可验证的目标，比如复现步骤、期望结果、相关文件或页面。
  • 代理只响应允许名单里的账号，陌生人 @ 不会触发。
  • PR 仍然需要人 review，合并和最终判断留在人这边。

Superagent 省下的是从一条评论到 PR 之间的重复劳动，让人只处理需要判断的部分。
